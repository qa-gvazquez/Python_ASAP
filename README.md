Python ASAP

Como su nombre sugiere, este es un reposotorio que tiene por objetivo primordial que YO aprenda Python de la manera más rápida posible, y esto es con el método de Feynman, enseñándote a tí.


No me gusta perder el tiempo viendo videos, por que cada instructor se repite a si mismo en varias ocasiones, y en otras omite información elemental que se requiere para otras lecciones más adelante.

Este curso autodidacta está pensado para personas que tienen un conocimiento básico de computación, y se asume que entienden cómo copiar, pegar y hacer click.

Eso es todo lo que necesitas.

El curso DESTILA las lecciones de las siguientes fuentes, quitando la repetición de contenido y las lecciones de repaso. Vamos a ir incrementando el conocimiento, pero no hay vuelta atrás. Si tienes dudas, puedes regresar cuando quieras.

El curso está pensado para 2 niveles de estudiante, el total novato y el medio, o que viene de otro lenguaje.

Para realizar los ejercicios, puedes usar las herramientas de W3Schools, o CLONAR mi ambiente de Visual Studio Code.

Personalmente recomiendo los segundo, en VSC dividir la pantalla y a la Izquierda leer el archivo de la lección, mientras a la Derecha se abre el archivo del código y se ejecuta `sólo una parte` con la extensión `Code Runner`.
