# Pyton ASAP

Este es un conjunto de lecciones de Python tomados de [W3Schools Python](https://www.w3schools.com/python/python_getstarted.asp).

También las lecciones de Brais Moure y su video [Curso COMPLETO de PYTHON desde CERO para PRINCIPIANTES](https://www.youtube.com/watch?v=Kp4Mvapo5kc).

Su Repo: [Hello Python](https://github.com/mouredev/hello-python)

[Descargas - Python.org](https://www.python.org/downloads/release/python-3152/)

[The Python Tutorial](https://docs.python.org/3.15/tutorial/index.html)

Tiene por objetivo ser un SandBox para entender este lenguaje de programación.

## Windows

Estoy usando Visual Studio Code con las siguientes extensiones:

- Python extension for Visual Studio Code
- Markdown All in One
- Blockman - Highlight Nested Code Blocks
- Python Indent


## MAC
Se está utilizando el IDE de `PyCharm`, pero existen IDE's en linea como [online-python.com](https://www.online-python.com/)
para facilitar el aprendizaje.
