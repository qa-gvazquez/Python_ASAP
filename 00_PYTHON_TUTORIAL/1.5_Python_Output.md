
# 1. Python Output > 'print()' function

<details>

<summary>Print Text </summary>

## 1.1. Print Text

- You have already learned that you can use the `print()` function to display text or output values:

```python
print("Hello You!") # Single statement
```

- You can use the print() function as many times as you want. Each call prints text on a new line by default:

```python
"""
Multiple
statements
"""
print("Hello World!")
print("I am learning Python.")
print("It is awesome!")
```

## 1.2. Double Quotes

- `Text` in Python must be `inside quotes`. You can use either `"` double quotes or `'` single quotes:

```python
print('This will also work!')   # Single quotes
print("This will work!")        # Double quotes
```

## 1.3. Print Without a New Line

- By default, the `print()` function ends with a new line.
- If you want to print multiple words on the same line, you can use the `end` parameter:

```python
print("Hello World!", end=" ")
print("I will print on the same line.")
```
Output:
> Hello World! I will print on the same line.

- Note the syntax of `end` parameter.
- We add a space after it `end=" "` for better readability.
- HINT: That 'space' can be repalced with anything.

```python
print("Hello World!", end=" ❌ 🔥 ")
print("Next line will print on the same line.")
```

Output:
> Hello World! ❌ 🔥 Next line will print on the same line.

</details>

# 2. Python Output > Numbers

<details>

<summary>Print Numbers </summary>

## Print Numbers

- You can also use the print() function to display numbers:
- However, unlike text, `we don't put numbers inside quotes:`

```python
print(3)
print(358)
print(50000)
```

> You can also do math inside the print() function:

```python
print(3 + 3)
print(2 * 5)
```

Output:
```
6
10
```

## Mix Text and Numbers

- You can *combine text and numbers* in one `print()` output by **separating them with a comma**:

```python
print("I am", 35, "years old.")
```
Output:
>I am 35 years old.

</details>
